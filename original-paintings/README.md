# Original story paintings

The full-size painting for every story as it was on 22 November 2026, saved
before the stories were given new paintings in the bright style.

Each file is named after its story's web address (the slug), so
`the-weight-of-money.webp` is the painting for
https://www.badmaddangerous.com/#/story/the-weight-of-money

134 paintings. Nothing on the website uses this folder; it is a backup.
